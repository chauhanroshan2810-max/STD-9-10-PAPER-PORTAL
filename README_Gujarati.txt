STD 9-10 QUESTION PAPER PORTAL – FIREBASE HOSTING

આ પેકેજ Firebase Hosting માટે તૈયાર છે.

મહત્વનું:
1. .firebaserc માં YOUR_FIREBASE_PROJECT_ID ને તમારા Firebase Project IDથી બદલો.
2. Firebase CLI/Cloud Shell માં આ folder ખોલો.
3. firebase deploy --only hosting ચલાવો.
4. Deploy પછી https://PROJECT_ID.web.app પર portal ખુલશે.

આ versionમાં Std 10 Social Science માટે 25 ગુણનું paper generator છે.

Firebase Hosting official quickstart:
https://firebase.google.com/docs/hosting/quickstart
